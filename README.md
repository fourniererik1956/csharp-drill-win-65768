## About csharp-drill

csharp-drill is a browser-based study tool for C# and .NET interview preparation. It is designed around quick review sessions, helping you move through flashcards and quiz questions with minimal setup and fast keyboard interaction.

The app keeps everything in one self-contained page, so it is easy to open and use without a separate desktop install. Progress is saved in the browser, which makes it convenient to return to your study state and continue spaced repetition sessions over time.

---

## Features

- Keyboard-driven recall cards for rapid practice
- Multiple-choice quiz mode for interview-style review
- Leitner system support for spaced repetition scheduling
- Browser-based workflow with no desktop runtime needed
- Single self-contained page for simple hosting and sharing
- Browser-saved progress to preserve study state
- Focused on C# and .NET preparation
- Lightweight structure suited to short study sessions

## Usage

Start by choosing the recall card flow or the multiple-choice quiz mode.

Typical study flow:
1. Open the page in a modern browser.
2. Review a card prompt.
3. Answer with the keyboard or select an MCQ option.
4. Let the Leitner progression adjust what comes next.
5. Return later to continue from saved browser progress.

For interview prep, you can alternate between quick recall rounds and quiz rounds to cover both memory and recognition.

## FAQ

### How do I keep my progress?
Progress is saved in the browser, so use the same browser profile if you want to continue where you left off.

### Can I use it offline?
If the page and its assets are already available locally or in your browser cache, you can continue working without relying on a separate app install.

### Where do I change the study content?
Update the page data or configuration used by your hosted copy. The exact location depends on how the repository is packaged.

### What if the page does not open correctly?
Check that you are using a current browser and that the file or static host is serving the HTML page as expected.
